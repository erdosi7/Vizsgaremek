# Controller mappa

A controllers mappában lévő fájlok tartalmazzák az egyes funkciókhoz kapcsolódó logikát. Minden controllerben megtalálhatók azok a függvények, amelyek a beérkező kéréseket feldolgozzák.

![Controllers kód](/img/controllers-kod.png)

A fájlok végén a függvényeket exportáljuk, így más fájlok is használhatják őket.
