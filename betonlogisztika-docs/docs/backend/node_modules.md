# Node_modules mappa

A node_modules mappa tárolja a Node.js alkalmazásunkhoz telepített összes külső csomagot és könyvtárat. Ezeket a csomagokat az npm (Node Package Manager) segítségével telepítjük és a package.json fájlban definiáljuk őket.

A mappa tartalmazza például az express-t a szerver működtetéséhez, a mysql2-t az adatbázis kapcsolathoz, a bcryptjs-t a jelszavak titkosításához, a jsonwebtoken-t a token kezeléshez, valamint a jest és supertest csomagokat a tesztek futtatásához.

A package-lock.json fájl biztosítja, hogy minden fejlesztői környezetben ugyanazok a csomagverziók kerüljenek telepítésre, ezzel kiküszöbölve az esetleges verzióeltérésekből adódó hibákat.
