# Server.js fájl

- Importálja az app objektumot az app.js fájlból, amely tartalmazza az Express alkalmazás teljes konfigurációját
- Meghatározza a portot a környezeti változóból vagy alapértelmezetten 3000-et
- Elindítja a szervert az app.listen() metódussal, amely elindítja a HTTP szervert és figyelni kezd a beérkező kérésekre
- Kiírja a konzolra a szerver sikeres indulását jelző üzeneteket, amelyek tartalmazzák a portszámot és a helyi elérési útvonalat
