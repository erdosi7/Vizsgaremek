# Partnereink

A partnereink oldalon a felhasználók megtekinthetik a betongyártó cégek listáját és azok elhelyezkedését egy interaktív térképen. Az oldal betölti a partnereket a backend API-ról (/api/partnerek), majd a Leaflet térképkönyvtár segítségével jeleníti meg őket, egyedi markerekkel.

![Partnereink](/img/partnereink.png)

A térképen lévő markerekre kattintva megjelenik a kiválasztott partner részletes infóablaka, amely tartalmazza a cég nevét, telephelyét, telefonszámát és weboldalát. Az oldal tetején egy felhívás található a csatlakozásra, alul pedig az együttműködés előnyei olvashatók. Az oldal a főoldalon bemutatott egységes fejléccel és lábléccel rendelkezik.
