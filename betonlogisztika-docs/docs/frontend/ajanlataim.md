# Ajánlataim

Az Ajanlataim.jsx oldalon a felhasználó megtekintheti az összes korábban leadott ajánlatát, amelyek státusz szerint láthatók. Az oldal betölti az ajánlatokat a backend API-ról (/api/ajanlataim), majd kártyák formájában jeleníti meg őket, ahol látható az ajánlatszám, betongyártó cég, beton típus, mennyiség, helyszín, dátum, nettó és bruttó összeg.

![Ajánlataim](/img/ajanlataim.png)

Az ajánlatokhoz részletes költségbontás is tartozik, amely kattintásra lenyitható. Az elfogadott ajánlatokból egy gomb segítségével megrendelés indítható, az elutasított vagy lejárt ajánlatok pedig törölhetőek. Az oldal a főoldalon bemutatott egységes fejléccel és lábléccel rendelkezik.
