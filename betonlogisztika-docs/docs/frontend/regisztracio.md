# Regisztráció

A regisztrációs felület a Regisztracio.jsx komponens tartalmazza. Az űrlapon a következő mezők találhatók: teljes név, email cím, telefonszám, jelszó és jelszó megerősítése. Ezek a mezők kitöltése kötelező, a cégnév opcionális.

![Regisztráció](/img/regisztracio.png)

A jelszó mezők mellett itt is megtalálható a szem ikon a jelszó láthatóságához. Az űrlap alján két checkbox található az ÁSZF és az Adatvédelmi Nyilatkozat elfogadásához, amelyek hivatkozásként elvezetnek a megfelelő oldalakra. Sikeres regisztráció után egy sikeres visszajelző animáció jelenik meg, majd 3 másodperc után a felhasználó automatikusan visszairányul a bejelentkezési felületre.
