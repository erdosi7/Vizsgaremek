# Főoldal

A Home.jsx komponens a főoldal, a webalkalmazás belépési pontja, amely bemutatja a céget és szolgáltatásait. Az oldal tetején található a navigációs menü, amely a főoldal, megrendelés, ajánlatkérés, kapcsolat és partnereink oldalakra mutat.

![Főoldal hero](/img/fooldal.png)

A jobb felső sarokban lévő felhasználói ikonra kattintva nyílik a fiók menü (megrendelések, ajánlatok, kijelentkezés). Az oldal tartalmaz egy hero szekciót ajánlatkérés gombbal, 3 kártyát a szolgáltatásokról, egy bemutatkozó részt, valamint 6 beton típust bemutató kártyát.


![Beton típus 2](/img/fiok1.png)
![Beton típus 3](/img/fiok2.png)

Az oldal alján elérhetőségek, jogi hivatkozások és közösségi média ikon található.
