# Jogi oldalak (Impresszum, ÁSZF, Adatvédelmi Nyilatkozat)

Az Impresszum.jsx, AltSzerFelt.jsx és AdatvedelmiNyil.jsx oldalak a cég hivatalos jogi információit tartalmazzák.

![Jogi oldalak](/img/jogi-oldalak.png)

Az impresszum tartalmazza a cégadatok, vezetőség, bankszámla, nyitvatartás és szolgáltatási terület részletes leírását. Az Általános Szerződési Feltételek szabályozza a rendelés menetét, árakat, fizetési feltételeket, szállítást, minőségi garanciákat és lemondási lehetőségeket. Az Adatvédelmi Nyilatkozat tájékoztat a kezelt személyes adatokról, adatkezelési célokról, az érintettek jogairól, valamint a sütik használatáról. Az oldal a főoldalon bemutatott egységes fejléccel és lábléccel rendelkezik.
