# Kapcsolat

A Kapcsolat.jsx oldalon a felhasználók elérhetik a céget egy űrlap kitöltésével, amely az EmailJS szolgáltatáson keresztül küldi el az üzeneteket. Az oldal tartalmazza a cég elérhetőségeit, egy Google Maps térképet a pontos helyszín megjelenítéséhez, valamint a betonkeverő járművek bemutatását képek és műszaki adatok formájában.

![Kapcsolat](/img/kapcsolat.png)

Az űrlap validálja a megadott adatokat, és sikeres küldés esetén visszajelző üzenetet jelenít meg.
Az oldal a főoldalon bemutatott egységes fejléccel és lábléccel rendelkezik.
