# Megrendeléseim

A Megrendeleim.jsx oldalon a felhasználó megtekintheti az összes leadott megrendelését az adott státuszokkal. Az oldal betölti a megrendeléseket a backend API-ról (/api/megrendeleim), majd kártyák formájában jeleníti meg őket, ahol látható a megrendelésszám, ajánlatszám, beton típus, mennyiség, betongyártó cég, szállítási cím, dátum, adószám, valamint a végösszeg.

![Megrendeléseim](/img/megrendeleim.png)

A sikertelen státuszú megrendelések törölhetőek egy gomb segítségével.

Az oldal a főoldalon bemutatott egységes fejléccel ás lábléccel rendelkezik.
